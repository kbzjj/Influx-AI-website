## 本次适配

直接使用项目内保存的 Shinta 原始 Framer / React / Motion / Lenis 运行时，保留首屏视频堆叠、波浪文字、滚动背景变化、文字进场、资源影像、彩色服务叠卡、四阶段卡片、按钮悬停及页脚图形和视差。Influx Logo 与数字 DIN 字体来自项目现有资产。

首页顺序：首屏 → 平台条 → 营销问题转场 → 全球资源 → 自有 AI 与产品能力 → 四项营销服务 → 项目报价 → 合作流程 → 联系表单 → 页脚。以 Shinta 的原区块顺序和视觉为优先，服务导航直接定位到服务卡片。

产品能力使用原案例卡组件，替换为 Influx 四张产品截图并提供完整查看。工具价格使用原定价卡组件，适配 Free、Plus、Pro / Enterprise；不提供原模板年付切换。模板案例成绩、客户评价、团队介绍、博客与 FAQ 未进入业务页面。没有加入新的客户或效果数据。

联系表单和计算器采用模板的双栏、字段和按钮视觉进行必要扩展；平台条、补充资源数据、订阅边界和页脚链接按业务内容适配。这些部分属于内容适配，不声称与原模板每个区块逐像素相同。

## 文件

- `index.html`、`pricing.html`、`free-tools.html`：三个页面入口。
- `runtime/`、`assets/`、`cms-assets.js`：本地运行时及素材；`assets/influx/` 为品牌、DIN、产品截图和平台图标。
- `influx.css`、`influx.js`：中文排版与业务交互。
- `scripts/content.py`：业务文案及少量 HTML 内容片段。
- `scripts/build.py`：从本目录 `_source/shinta/` 重建三页和适配模块。
- `scope.json`、`asset-manifest.json`：范围、来源与当前文件校验值；调整过的原模块同时保留原始哈希。
- [源码学习索引](STUDY_GUIDE.md)、[验证记录](qa/verification.md)。

重建命令：

```sh
python3 versions/方案五/scripts/build.py
```

重建会重写三个 HTML 与运行时模块；文案和结构应修改 `scripts/content.py`、`scripts/build.py`，不要只改生成结果。重建不依赖 skill 目录，不会修改模板中心。方案五是项目实体目录，没有软链接，没有模板中心登记信息。
