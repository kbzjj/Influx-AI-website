## 动效与交互

- 本地 GSAP / ScrollTrigger 驱动影像滚动位移、逐词显现、星形旋转及桌面产品叠卡。
- 本地 Lenis 实现平滑滚动；导航下滚隐藏、上滚恢复，键盘聚焦时保持可见。
- 视频进入视口时播放，离开视口、隐藏标签页或暂停动效时停止；中心视频可单独播放／暂停。
- 原生 FAQ 折叠、领域图片水平轮播、菜单遮罩及键盘焦点管理。
- `prefers-reduced-motion` 下不启用平滑滚动与 GSAP 动效，视频保持封面，产品卡片改为常规流式布局。保留文字、图片和全部功能。
