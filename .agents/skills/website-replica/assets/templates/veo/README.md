# Veo 完整公开前端学习模板

来源：https://veo.framer.ai/  
保存日期：2026-10-23

用户确认范围为首页及导航可到达的所有同源公开子页面，共 19 页。包含 Features、Gallery、Pricing、Contact、Blog 列表及 9 篇文章，以及 4 个法律页面。保留原始 Framer HTML、CSS、React / Motion / Framer 模块、页面路由、动画与 CMS 数据。614 个资源已保存至本地，其中 23 个 MP4 视频。资源约 347 MiB；额外保留了原始文本和模块源码，便于学习。

## 打开

双击项目根目录或本技能目录中的 `启动模板中心.command`，访问 <http://127.0.0.1:4176/>，点击 Veo 封面。中心会自动启动独立模板端口，不需要记住单个模板的地址。

不要使用普通静态服务器替代中心的预览服务：Framer 客户端路由和 CMS 的分段数据请求需要所附服务器支持。

## 文件

- `index.html`：首页；其他页面按原始路由保存在 `features/`、`gallery/`、`pricing/`、`contact/`、`blog/`、`legal/`。
- `runtime/`：原始 Framer ESM 模块，保持 import 图和行为，仅适配本地资源及 CMS 地址。
- `assets/`：本地图片、字体、视频及完整 `.framercms` 数据文件。
- `_source/`：未重写的原始页面与模块文本，以及之前首页参考快照的记录。
- `asset-manifest.json`：原 URL、本地路径、大小和哈希。
- `scope.json`：用户确认范围和页面清单。
- `template.json`：统一模板中心的元数据。
- `scripts/mirror.py`：本站的保存/刷新脚本。刷新会重写页面与模块，应先审查手工改动，不要直接当作增量更新。
- `STUDY_GUIDE.md`：源码与动效学习索引。
- `qa/`：实际截图、静态资源和交互验证记录。

## 本地适配

移除了独立统计脚本，保留作者署名、模板推广及 Framer 视觉标识。商业购买、下载和作者链接仍指向原站的外部服务；本地演示不提供这些服务。表单只显示明确的本地预览反馈，不向原站发送数据。

Framer CMS 二进制内容保持原始字节与索引范围。本地服务器按请求返回所需分段，模块通过当前预览 origin 构造数据地址；避免把根相对路径误当作 `new URL()` 的绝对 base。图片/视频随机播放帧、跑马灯相位及设备渲染可能造成截图差异，不据此声称全设备逐像素一致。

原 `references/veo-public/` 是指向此目录的兼容链接；此处已由之前的部分联网首页快照升级为完整公开页面与本地运行时。
