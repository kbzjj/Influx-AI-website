## 设计方向

唯一模板参考为 Veo 的公开演示 <https://veo.framer.ai/>，采用亮色背景、悬浮人物卡片、圆角容器和克制动效，延续 Influx 现有品牌。未购买或复制 Veo 商业模板代码与素材。

原有点阵地球保留，并加入装饰头像与连接线。人物照片仅用于视觉演示，不代表真实平台达人、客户或合作背书，没有附加虚构姓名、粉丝数据或推荐语。原站的 `210M+`、`120+` 等既有文案原样保留，本次未另行核实这些业务数据。

主要设计令牌：主文字 `#292631`、品牌紫 `#6952e5`、浅紫 `#f4f1ff`、边线 `#eae7ef`、内容最大宽度 `1160px`、主要卡片圆角 `28px`。字体为 DM Sans、Noto Sans SC，延用原站 Google Fonts 来源并提供系统字体回退。首次加载字体仍需联网；图片及业务脚本已存放本地。
