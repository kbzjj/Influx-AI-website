# Veo 公开演示首页本地快照

来源：https://veo.framer.ai/
抓取日期：2026-10-22

`original.html` 是公开站点响应原文（包含内联 CSS）。`index.html` 为本地查看版本，保留作者署名、购买入口和原内容，部分图片指向本地副本，原站内页链接改为原站绝对地址，并去掉统计脚本。

`assets/` 下载了首屏/部分前端展示资源和公开入口模块，映射见 `downloaded-assets.json`。`public-assets.json` 是页面引用资源清单。

这不是 Framer 可编辑项目或商业模板源文件。HTML、CSS 和部分公开资源已保存在本地；页面仍通过原 CDN 加载其余图片、字体及 Framer 运行时模块，不能声称完整离线镜像。原站各内页链接仍打开原站，不在本次抓取范围内。

该目录用于本机视觉对照，不作为 Influx 官网发布目录。第二方案使用独立实现及项目素材。
