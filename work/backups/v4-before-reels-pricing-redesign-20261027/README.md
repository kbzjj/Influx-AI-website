## 文件与目录

- `index.html`、`pricing.html`、`free-tools.html`：直接运行的三个页面，不需要构建或安装依赖。
- `assets/`：模板原始素材、字体及原始运行时；`assets/influx/` 为方案三品牌资产、产品图与字体。
- `influx.css`：品牌字体/主色/导航，以及中文长度和子页的必要适配。
- `content-zh.json`：本轮中文修订的源文案，构建时合入 `copy.js`，保留原英文值；`copy.js`：浏览器使用的中英文内容；`influx.js`：语言、菜单、统一表单、截图、法律预览、计算器。
- `runtime-bridge.js`：字体加载后的刷新、首屏锚点定位、隐藏标签页视频暂停；原始动画仍由 Webflow / GSAP 执行。
- `scope.json`、`asset-manifest.json`：本次范围及资源来源；`_source/` 保存参与适配的原始 HTML 文本。
- `scripts/`：本次抽取和内容装配工具。网站本身不依赖这些脚本运行。可在项目根目录执行 `python3 versions/方案四/scripts/build.py`，从本目录 `_source/` 的快照重建。
- [源码学习索引](STUDY_GUIDE.md)、[实际验证记录](qa/verification.md)。

实体保存在本项目 `versions/方案四/`，是普通目录；页面与重建均不依赖 skill 目录。方案三未修改。原模板中心登记仅作为项目内历史资料保存在 `_source/former-template-registration.json`，不再参与模板发现。
