# 网站视觉与动效复刻

交付忠于参考站的本地前端及动效，而不是相似风格的新设计。优先复用原站公开 HTML、CSS、字体、图片、视频和运行时，保留结构、节点标识和动画时序；不能将静态截图或嵌入原站 iframe 当作复刻成果。

用户只要求打开已有模板/模板中心时，读取 [模板库与统一入口](references/template-library.md) 并启动预览，不启动新复刻或重新确认已有范围。新复刻执行下面的范围确认流程，完成后按同一参考自动入库。

## 先确认范围

**每次新复刻任务都先请用户确定范围，再下载、批量抓取或写入复刻文件。** 用户在本次请求中已清楚指定范围时，简要复述其范围即可，不重复索要确认。只给一个 URL 不能推断为全站，也不能自行默认只做首屏。

范围尚不明确时，使用一条简洁的问题确认：仅所给页面、指定页面列表/栏目，还是公开全站；说明会包含所选页面的完整滚动内容和交互动效。用户选择全站但规模未知时，可先进行只读导航/站点地图盘点，列出页面类别和预计数量，再确认实际抓取边界。明确不同域名、语言、分页、查询参数页面是否在范围内；只问会改变本次工作的事项。

允许在确认前检查当前项目，以及查看所给页面以帮助解释范围；不要先行递归访问所有子页面。确认后保存本次约定到输出目录的 `scope.json`，含来源、包含/排除范围、页面清单、重点交互及验收视口。发现需要新增页面、换成手写近似实现、缺失关键素材等会影响约定效果的问题时，直接询问用户，并继续不依赖该答案的已授权工作；等待本身不构成同意。

## 本项目约定

- 复刻成果集中保存到本技能的 `assets/templates/<site-slug>/`，每个模板保留一个实体目录；保留现有项目网站、兼容预览入口和未提交改动。目录冲突时先检查并选用新名称，不能用新快照覆盖手工修改。
- 不自动发布上线或安装到用户全局 skill 目录。完成复刻后启动本地预览，打开页面供用户查看；保留该预览服务并说明停止方式。
- 只实现本次确认的前端范围。业务表单使用明确的本地演示反馈，不能冒充真实提交或向原站发送测试数据。
- 随成果提供源码学习索引和验证证据。作者署名和原有视觉元素按参考保留；不要习惯性套用 Reels 的字体、布局、推广卡片处理或其他站点特例。

## 观察与选择实现

先检查项目约定和已有预览工具，再通过可用的浏览器工具观察原站。记录页面在相同视口下的首屏、完整滚动布局，以及本次涉及的菜单、悬停、轮播、Tabs、FAQ、视频、滚动触发动画。对动画观察开始/进行/结束及反向滚动状态，避免只看最终截图。

读取公开页面及其资源，判断静态输出是否足以本地运行。不要将浏览器脚本执行后生成的 DOM 误认为完整可迁移源码。对于 Webflow 等有可用公开输出的站点，保留运行时、动画配置、页面 ID、元素 ID 和脚本顺序。

对可独立运行的静态 HTML / CSS / JS，读取 [静态本地化](references/static-localization.md)，使用附带的 `scripts/snapshot.py` 下载**明确列出的页面**，不递归抓取页面。它会本地化常见资源和 CSS 依赖，保留原始文本副本并生成映射清单。不要把工具成功退出视为视觉完成。

对于 SPA、Next.js、Nuxt、Framer、动态模块、远程接口、canvas/WebGL 或复杂滚动运行时，先读取 [运行时与动效处理](references/runtime-and-motion.md)。根据实际公开代码与运行结果补齐所需依赖，不能仅凭技术栈名称认定无法复刻。若必须改写框架或重新实现核心效果，解释具体缺口和影响，先由用户决定；不要静默降级。缺失原始视频、字体或图片时，不用 AI 素材或相似素材代替并宣称 1:1。

## 实现与核对

按原站还原字体与字重、尺寸、留白、内容宽度、比例、配色、边框、遮罩、层级及响应式断点。优先排除资源/字体加载和脚本初始化问题，再调样式；不要用临时 CSS 掩盖运行时失败。

动效保留方向、距离、旋转、缩放、透明度、缓动、时长、stagger、滚动区间、scrub、pin、循环和暂停/恢复行为。平滑滚动、滚动触发及 ticker 应按原站同步，不重复初始化引擎。

菜单的 `href="#"`、Tabs 锚点、SVG fragment 和 `data-*` 目标必须保留语义。不要全局字符串替换脚本中的 URL，或无区别删除 SRI / CSP。只调整确实因本地化失效的约束，详见静态本地化参考。

完成可辨认版本后启动本地服务并打开预览；使用当前环境支持的浏览器工具进行交互，不另行搭建绕开工具约束的浏览器控制链路。无可用浏览器时说明无法完成动态视觉验收；有缺口就记录，不声称全部验证通过。

读取 [对照验收与交付](references/verification.md)，检查相同视口/状态下的原站和本地版本。运行附带的 `scripts/audit.py` 查缺失文件和外部依赖；修复关键差异后再针对性复测。保留截图、尺寸数据、交互结果与仍需联网的项目，区分“已验证”“未验证”和“受限”。

## 交付内容

输出应包含可运行页面、本地素材和运行时、`scope.json`、资源映射清单、实际完成的 QA 证据、本地启动方式及学习文档。学习文档指出本次实际 CSS / JS / 页面入口、主要区块选择器、动画实现位置和可调整参数；不要只给通用前端教程。

最终回复提供预览 URL、源码位置、学习文档和关键限制。可附本地截图。只有关键视觉和交互有对照证据、范围内页面与资源完整时，才可以报告相应验收完成；“页面宽高相同”不能代替逐像素或动效验收。用户要求 1:1 是目标，不是对任意网站可无条件实现的保证。

每次完成后按 [模板库与统一入口](references/template-library.md) 写入模板元数据和真实封面，核对中心入口。后续用户可直接点击封面查看，无需重新配置各模板的启动地址。
